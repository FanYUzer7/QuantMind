## 事前方案（2026-11-22）

研究问题是股票身份直连、静态身份路由和动态特征路由各自如何影响泛化。根据上一轮的训练/验证分离与身份均值诊断提出假设，不把推理时关闭通道当成因果重训练证据。方案在本轮训练前固定。

| 结构 | 市场输入 | 身份直连 | 路由信息 | 其他股票汇聚 |
|---|---|---|---|---|
| local | 无 | 无 | 无 | 无 |
| market | 有 | 无 | 无 | 无 |
| relation | 有 | 有 | 股票 ID | 有 |
| route_only | 有 | 无 | 股票 ID | 有 |
| state_relation | 有 | 无 | 当天的个股历史特征编码 | 有 |
| uniform_peers | 有 | 无 | 均匀权重 | 有 |

六种结构共享相同个股编码器和预测头，未启用的输入通道置零。新增状态投影放在原层初始化之后，使旧结构的随机初始化保持一致。route_only 不代表完全消除身份记忆：ID 仍能通过查询分组、对其他股票的分配影响输出。state_relation 不使用股票查表参数，但输入特征仍可能间接反映规模、流动性等个股风格。

## 输入与模型

固定复用上一轮按训练期相关性选择的 27 个因子、五个精确交易日历史及缺失指示，输入 270 维，编码器 270→64→32，市场 13 维。训练 2018—2022，2023 用于 checkpoint 选择；2024—2025 是此前已观察的探索性测试，不声称新盲测。原始输入不重复保存；引用既有行情/因子和按哈希固定的 v1 预处理代码。供应商 PIT、精确历史涨跌停规则仍未认证。

静态路由为 $a_i=\mathrm{softmax}(e_iW/0.5)$，$e_i\in\mathbb R^{16},W\in\mathbb R^{16\times8}$。状态路由为 $a_{i,t}=\mathrm{softmax}(Uh_{i,t}/0.5)$，$U$ 为所有股票共享的映射。uniform_peers 对组均匀分配，等价于平均汇聚其他可用股票的状态。

所有汇聚均剔除目标股票自身，缺失股票不参与，不按未来标签可得性筛选信息来源。分组数量 8 固定，无真实行业监督；不是完整 MoE，也不能将分组解释成已发现的因果板块。

损失为股票未来五日收益的当日百分位排名减 0.5 的平方误差，日期内平均后日期间等权。关系路由保持原熵/均衡正则系数各 0.001，避免本轮又同时改变正则强度。状态路由对可用股票计算该正则；静态 ID 路由只对已知身份计算。

## 训练与 checkpoint

三个固定 seed：42、123、2026；每批 16 个完整日期，AdamW lr=0.001、weight decay=0.0001、梯度裁剪 1，共 12 轮。不按测试期指标挑模型或 seed。各结构同 seed 使用相同初始化及训练日期顺序。

每轮结束后，用**同一个 checkpoint**重新计算完整训练/验证 MSE，修复上一轮蓝线是在线 batch 均值而橙线是轮末值的比较限制。同时保留每次优化更新的 MSE、路由正则、目标值、梯度范数和学习率；AdamW 的衰减不伪装成显式损失分项。

主结果选择各 seed 验证 MSE 最小的 checkpoint，严格相等时保留较早一轮；第 12 轮单独保留并评价，用于区分结构改动与 checkpoint 选择的影响。**2023 的选后指标是选择内指标**，不是无偏泛化估计。六种结构都使用同一选择规则，不能只给新模型早停、让基线固定过拟合。

每个结构对三个 seed 在当日全部 feature-ready 股票上的分数百分位取平均作为集成。沿用旧的排名集成以避免因为上一轮集成结果差而事后换成最有利的方法；这不等于三个组合收益的平均。本轮不运行单 seed 组合回测，但保存全部 seed 的预测、IC 和 checkpoint，明确这一范围。

## 对照与验收

- route_only 对 relation：隔离直接身份输入，分组身份仍保留。
- state_relation 对 route_only：用共享特征路由替代静态 ID 路由。
- state_relation 对 uniform_peers：区分学习的股票关联与一般市场汇聚。
- market 对 local：单独跟踪市场输入的影响。
- route_only 对 market：检验保留静态 ID 路由的剩余影响。
- uniform_peers 对 market：检验一般跨股票平均是否有增量。

同时报告选中与末轮 checkpoint 的上述对照，20 日移动区块 bootstrap 500 次，无多重检验校正。固定末轮 local/market/relation 应复现上一轮各 seed 的预测，容差 1e-5，以确认未经改动的支路未被悄悄改变。仅归因于本次研究设置，不外推所有结构。

六个结构的验证选中与固定末轮集成、旧树模型和同池等权各跑 0/10/20bp，共 42 场景。结构结论同时检查固定末轮；best 结果描述验证选择策略，不能单独归因于结构。沿用 1000 万初始现金、top20、五日调仓、T 分数于 T+1 收盘成交、目标 95% 股票、100 股买入单位、0.5% 日成交量容量和旧 ST/涨跌停近似。指数为无费用的沪深 300 价格指数。年化 252 日，Sharpe 无风险利率为 0。真实仓位可能因成交不足而偏离目标，风险暴露未匹配，不能单看累计收益。

验收包含通道隔离单测、模型重载、旧支路末轮复现、标签与输入父实验哈希约束、验证选择规则检查及独立组合对账。未完成的验证不写成通过。图的结果数据为 training-trace.csv、optimizer-trace.parquet、daily-results.parquet；生成代码随记录归档，权重仅引用 models。
